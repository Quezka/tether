# Tether

Your Android phone on your computer: notifications (with replies), text messages, calls, files and the clipboard,
over your home network and end-to-end encrypted. Part of the Quezka suite.

- **Computer:** Rust, in [suite-rs](https://github.com/Quezka/suite-rs) (`crates/tether`); this repo packages it.
- **Phone:** the Android app in `app/` (Kotlin, Compose, Material 3).
- **Protocol:** [docs/PROTOCOL.md](docs/PROTOCOL.md).
